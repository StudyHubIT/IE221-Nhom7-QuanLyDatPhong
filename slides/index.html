Mô hình dữ liệu

Chỉ chiếu sơ đồ. Nhấn 3 nhóm (auth / phòng-đặt / tiền) rồi luồng USERS → DATPHONG → CT_DATPHONG → PHONG, rồi PAYMENTS → REFUNDS. Không đọc từng cột. Nếu GV hỏi chi tiết, nói USERS/ADMINS không kế thừa nhau.

Kiến trúc

Thư việnMục đích trong đồ án
FastAPIFramework HTTP: router, Depends, CORS. Tự sinh OpenAPI.
Swagger UI/docs — thử endpoint, Authorize bằng token login.
UvicornASGI server chạy app, reload trong Docker.
PoetryQuản lý dependency & virtualenv (pyproject.toml / lock).
Pydantic v2Validate body/query, serialize JSON, khớp contract OpenAPI.
pydantic-settingsĐọc .env: CORS, DATABASE_URL.
SQLAlchemy 2ORM: model = bảng; session theo từng request.
AlembicMigration schema (pages → 12 bảng khách sạn). Container chạy upgrade head.
psycopgDriver PostgreSQL.
pytest + httpxTest API (backend/tests).

Sơ đồ 3 container trước. Thư viện: nhấn FastAPI + Pydantic + SQLAlchemy/Alembic. Swagger để GV thấy API. Poetry = cách cài, không phải runtime request.

Claude Code

Bốn skill gắn với luồng làm việc của nhóm

Nằm ở .claude/skills/. Mô tả việc bằng lời — agent tự nhận skill và làm đúng convention repo.

add-feature-endpoint

Hiện thực 1 endpoint FastAPI: model → schema → router. Thay stub bằng query SQLAlchemy, không bịa field ngoài OpenAPI.

wire-frontend-page

Nối 1 trang apps/web từ mock-data sang apiFetch. Giữ nguyên UI; chỉ nối khi backend đã hết stub.

task-scope-check

Audit task A/B/C/D: endpoint nào còn stub, trang nào chưa nối API, có lỡ đụng phạm vi người khác không. Chỉ đọc, không sửa code.

seed-reset

Reset stack dev (Postgres + API + Next.js) khi DB lệch state. Hỏi xác nhận trước khi docker compose down, rồi seed lại.

Không đọc hết 4 card. Nêu một vòng: hiện thực API → nối trang → check phạm vi; seed-reset khi môi trường hỏng. Skill là hướng dẫn cho agent, không phải thư viện runtime.
