User & Auth

USERSADMINSROLESPERMISSIONS

Khách và admin là hai thực thể độc lập. Admin ↔ role ↔ permission là N:N.

Phòng & đặt

LOAIPHONGPHONGDATPHONGCT_DATPHONG

Một loại có nhiều phòng. Một đơn đặt nhiều phòng qua chi tiết; unique cặp (đơn, phòng).

Tiền

PAYMENTSREFUNDS

Thanh toán gắn đơn. Hoàn tiền gắn payment; approved_by trỏ admin, có thể null.

  • Luồng chính: USERS → DATPHONG → CT_DATPHONG → PHONG, rồi PAYMENTS → REFUNDS.
  • Trạng thái then chốt: phòng AVAILABLE / MAINTENANCE, đơn PENDING → CONFIRMED → CHECKED_IN → CHECKED_OUT / CANCELLED, refund REQUESTED / APPROVED / REJECTED.

Nhấn 3 nhóm rồi 2 câu quan hệ. Không đọc từng cột. Nếu GV hỏi chi tiết, nói USERS/ADMINS không kế thừa nhau.

Frontend & Docker — nói ngắn

apps/web: TypeScript, Next.js App Router, gọi REST qua apiFetch.

Docker Compose chạy 3 service: web, api (alembic upgrade rồi uvicorn), db.

Backend backend/app

main.py          FastAPI + CORS + router
core/            config, DB session, token
models/          SQLAlchemy ↔ bảng Postgres
schemas/         Pydantic = JSON in/out
api/deps.py      CurrentUser / CurrentAdmin
api/v1/          auth, catalog, bookings, admin

Một request: router → auth/DB dependency → query model → trả schema.

FE chỉ 2 câu. Docker 1 câu. Còn lại chỉ cây thư mục backend rồi sang slide thư viện.

Backend Python

Thư viện lõi và việc từng thứ đảm nhận

Thư việnMục đích trong đồ án
FastAPIFramework HTTP: router, Depends, CORS. Tự sinh OpenAPI.
Swagger UI/docs — thử endpoint, Authorize bằng token login.
UvicornASGI server chạy app, reload trong Docker.
PoetryQuản lý dependency & virtualenv (pyproject.toml / lock).
Pydantic v2Validate body/query, serialize JSON, khớp contract OpenAPI.
pydantic-settingsĐọc .env: CORS, DATABASE_URL.
SQLAlchemy 2ORM: model = bảng; session theo từng request.
AlembicMigration schema (pages → 12 bảng khách sạn). Container chạy upgrade head.
psycopgDriver PostgreSQL.
pytest + httpxTest API (backend/tests).

Nhấn FastAPI + Pydantic + SQLAlchemy/Alembic là bộ ba. Swagger để GV thấy API. Poetry = cách cài, không phải runtime request.
